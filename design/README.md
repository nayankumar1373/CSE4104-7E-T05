# Design Files (Week 05)

| Folder / file | Content |
|---|---|
| `prototype/index.html` | Clickable high-fidelity HTML prototype with 25 screens, light and dark theme, and a mobile layout. Open it in a browser. Use the **All screens** button (bottom right) to jump to any screen. |
| `screens/` | PNG screenshots of every screen (desktop 1440 x 900), plus `mobile-*.png` (390 x 844) and `*-dark.png` |
| `flows/` | User flow diagrams and site map (`.png` and `.svg`, with Graphviz `.dot` sources) |
| `design-system.md` | Colours, typography, spacing and components |

The full explanation is in `documentation/CSE4104-7E-T05_UIDesign.pdf`.
Figma was not used; the HTML prototype is the design source.
