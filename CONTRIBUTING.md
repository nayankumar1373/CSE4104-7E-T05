# Contributing (Team CSE4104-7E-T05)

## Branches
- `main`: stable, demo-ready only (protected)
- `develop`: integration branch
- `feature/<module>-<short-name>` and `fix/<issue>` for work; open a pull request into `develop`

## Commits
`type(scope): message`, for example `feat(flashcards): add generate endpoint`.
Types: feat, fix, docs, style, refactor, test, chore.

## Pull requests
1. Link an issue and describe the change.
2. CI must pass (lint, type check, tests).
3. One other member reviews before merge.
4. The team leader tags each weekly state (`week-06`, `week-07`, ...).

## Definition of done
Works end to end, matches the designed screen, has tests, has no console errors, and is documented.
